# B8.3.2 fatal private failure

This runner uses original Envoy session owners, the qualified Awsh executable,
genuine selected Bash, public sockets, private pipes, process census and original
Wait calls. It adds no production entrypoint or replacement successful actor.
Supported qualification remains limited to the three proven Linux amd64 tuples.

The map preserves all 263 assigned B8.3.2 case IDs. It combines with the approved
67-case captured-closure map to retain the original 330-case B8.3 inventory.
It requires 242 phase/fault scenarios, six crossed cancel/resize scenarios and
two additional timing scenarios. The 14 contract cases reuse their applicable
causal proofs. The package case also requires the complete captured-closure
runner, session race suite and static inventory checks on the current candidate.
A map check alone proves no runtime behavior.

Each scenario runs a separate dedicated Envoy test process. Fault bytes enter
Awsh's actual result pipe. Retained Go overlays pause original acceptance,
positive partial writes or the original Wait call. They never replace a codec,
successful cleanup, process status or receipt. Launch faults are queued in that
same pipe before actor startup can race them. The real actor still launches,
owns Bash and exits through its original Wait owner.

Missing-EOF cases retain an actual writer. Unreaped cases hold the original Wait
before its kernel call and require the actual zombie to remain. Zero and
signalled outcomes come from the original process; neither becomes a successful
terminal result. Inspection scenarios stop a real worker process, then require
actual Kill and joined disposal. Crossed cases retain a decoded queued cancel
and an actual resize worker blocked before its ioctl. They reject resize
acknowledgement, private continue, operation results and late-input execution.

The late-closure proof observes real EOF near four seconds and releases the
original Wait near 4.8 seconds within the unchanged five-second barrier. It
checks actual observed order and the exact original deadline. It does not claim
one-millisecond host scheduling precision. The sender proof pauses an actual
positive partial control write near its original individual deadline. Fatal
drain must observe EOF after that sender deadline without adopting it.

An expired epoch remains a failure even when the harness later settles retained
actors to avoid leaks. Later settlement does not repair the original deadline,
missing EOF or missing reap evidence. Reploy termination reporting remains with
C8.2. No operation result or synthetic shell status is emitted by this assembly.

The complete native selection runs all 250 scenarios on all three genuine
targets. `--release`, `--phase`, `--variant`, `--crossed-only` and `--extra-only`
produce development subsets. `--check-map-only` validates only the inventory
partition. The default also runs six omission controls. `--proof-only` runs
only those negative proofs; `--native-only` omits them for development.
Each omission must trigger its specific assertion with actual actors.
Compilation failure or a different diagnostic cannot pass an omission control.

`coverage.py` verifies current source bindings, exact native proof identities,
both complete native matrices, all omission controls, and the session/protocol
results from the enclosing `go test -race -json ./...` validation log. It
retains the resulting 330-case evidence closure. The enclosing validation
receipt owns the Go log's exact candidate binding.
