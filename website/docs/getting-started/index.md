# Get Started With OmegaFlow

OmegaFlow turns scripted terminal and browser workflows into narrated,
rebuildable videos. You author the workflow as a Markdown recording file,
build it like other project output, and publish a player that can be rebuilt
when the product or documentation changes.

It is useful for product walkthroughs, interactive tutorials, agent
demonstrations, simulations, and other technical stories where a conventional
screen recording would be difficult to maintain.

## Build your first video

The shortest path takes about five minutes:

1. [Install OmegaFlow](./install.md) and its media prerequisites.
2. [Build your first video](./first-video.md) from the generated test
   recording.
3. Keep `action=watch` open while you edit and rebuild.

The first video proves that capture, presentation media, and local playback
work before you begin authoring a larger workflow.

## Where that leads

Use [Next steps](./next-steps.md) to choose a focused guide for terminal or
browser authoring, narration, presentation, and publishing.

OmegaFlow currently supports Linux and macOS directly, plus WSL using a host
browser for playback. See [Install and supported platforms](./install.md) for
the complete contract.
