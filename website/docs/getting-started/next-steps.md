# Next Steps

After the generated test video works, choose the path that matches your goal:

- Use the [terminal authoring guide](/guides/terminal-workflows/) for a
  command-line workflow.
- Use the [browser authoring guide](/guides/browser-workflows/) for a local
  application or browser interaction.
- Read [Concepts](/concepts/) for the mental model behind beats,
  presentation time, and reusable build output.
- Keep [Reference](/reference/) nearby when you need an exact field or command
  contract.

For an existing recording, `action=watch` is the normal editing loop and
`action=check` is the final non-mutating verification.
