# Add Guided Playback

Guided playback pauses at beat boundaries so the viewer can review a step,
copy a relevant command, or choose when to continue.

Enable Guided mode for the recording, then attach a `guide` to the beats where
the pause serves a real viewer task. Keep the summary short and include
commands only when the viewer is expected to run them.

Turning Guided mode off changes automatic pausing. It does not remove guide
content from the video. A guide with multiple commands uses the plural
**Copy commands** label.

Use player-control highlights sparingly to introduce an unfamiliar control;
the highlight ends when the viewer uses the control or the configured interval
ends.

See [Guide and player effects](/reference/recording-files/schema/#guide) for
the complete fields.
